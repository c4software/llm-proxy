llm-proxy — navigateur piloté

L'extension se connecte à votre proxy : les modèles qui y passent (le chat de la page, Codex, pi, omp…) peuvent alors agir dans ce navigateur, avec l'outil browser, sur les sites que vous autorisez.

Une de vos clés (tableau de bord, section Clés). Elle relie ce navigateur à votre compte : seuls vos appels y agissent. Laisser vide pour un proxy ouvert.
