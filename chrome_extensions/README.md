# Extensions de navigateur

- [`llm-proxy-browser`](llm-proxy-browser) : le navigateur piloté. L'outil
  hébergé `browser` du proxy agit par elle dans votre navigateur (Chrome,
  Edge, Brave de bureau), sur les sites que vous autorisez. Installation,
  sécurité et protocole : [docs/extension.md](../docs/extension.md).

Pour la charger : `chrome://extensions`, *mode développeur*, *Charger
l'extension non empaquetée*, puis choisir le dossier `llm-proxy-browser`.
